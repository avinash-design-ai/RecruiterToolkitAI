📖 How to Use LinkedIn Automation

Follow the steps below to download, launch, and use the LinkedIn Automation application.

STEP 1: Open LinkedIn Automation

From the Recruiter Toolkit AI home page, click Open Tool under LinkedIn Automation.

STEP 2: Download, Extract and Run

  1. Click the Download Windows Application button above.
  2. Locate the downloaded ZIP file in your Downloads folder.
  3. Right-click the ZIP file and select Extract All....
  4. Select a destination folder and click Extract.
  5. Open the extracted folder.
  6. Double-click the Recruiter Toolkit executable to launch the application.

STEP 3: Set Up LinkedIn Search

The Recruiter Toolkit LinkedIn search interface opens. Enter the required search information:

  • Company
  • Location
  • Max Profiles

Click Run Search to begin the LinkedIn automation workflow.

STEP 4: LinkedIn Login

Playwright opens a browser window and navigates to LinkedIn.

Because authentication is required, the LinkedIn Sign in page appears.

Important: Complete the LinkedIn login in the browser opened by the application.

STEP 5: LinkedIn Search Results

After you complete the LinkedIn login, Playwright proceeds to the LinkedIn search/results page.

STEP 6: Location-Filtered Results

The location-filtered LinkedIn results are displayed based on the search configuration.
