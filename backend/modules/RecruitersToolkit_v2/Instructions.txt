==========================================================
Recruiter's Toolkit - Installation Guide
==========================================================

System Requirements
-------------------
- Windows 10 or Windows 11
- Internet Connection
- Python 3.13 (or newer)

----------------------------------------------------------
STEP 1 - Install Python
----------------------------------------------------------

Download Python from:

https://www.python.org/downloads/

IMPORTANT:

During installation check:

[X] Add Python to PATH

After installation verify:

Open Command Prompt

python --version

or

py --version

----------------------------------------------------------
STEP 2 - Copy Recruiter's Toolkit Folder
----------------------------------------------------------

Copy the entire folder:

RecruitersToolkit_v2

to any location.

Examples:

C:\RecruitersToolkit_v2

D:\Tools\RecruitersToolkit_v2

C:\Users\<username>\Documents\RecruitersToolkit_v2

The folder DOES NOT have to be stored in the same location
as the developer's PC.

----------------------------------------------------------
STEP 3 - Install Required Python Packages
----------------------------------------------------------

Open Command Prompt.

Go to the project folder.

Example:

cd C:\RecruitersToolkit_v2

Install dependencies:

pip install -r requirements.txt

----------------------------------------------------------
STEP 4 - Install Playwright Browser
----------------------------------------------------------

Run:

playwright install chromium

This only needs to be done once.

----------------------------------------------------------
STEP 5 - Configure Desktop Shortcut
----------------------------------------------------------

Open:

Run Recruiter's Toolkit.vbs

Edit the following line:

WshShell.CurrentDirectory = "C:\RecruitersToolkit_v2"

Change it to wherever YOU saved the folder.

Example:

WshShell.CurrentDirectory = "D:\Tools\RecruitersToolkit_v2"

Also update the Run command if required.

Example:

WshShell.Run "py src\ui.py", 0, False

Save the file.

Create a Desktop Shortcut to the VBS file.

Double-click the shortcut to launch the application.

----------------------------------------------------------
Updating the Toolkit
----------------------------------------------------------

When a new version is shared:

1. Close the application.
2. Replace the RecruitersToolkit_v2 folder.
3. No reinstallation is required unless instructed.

----------------------------------------------------------
Troubleshooting
----------------------------------------------------------

If Python is not recognized:

Reinstall Python and select:

[X] Add Python to PATH

If Playwright reports browser not found:

Run:

playwright install chromium

If packages are missing:

Run:

pip install -r requirements.txt
